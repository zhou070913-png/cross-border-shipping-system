# 列表、客服同步与读取错误修复

2026-10-29，最新开发版独立发布；不迁移或清理数据库，不修改开发首版。

- 仓库收货、合包复核、出货客户列表及收货记录允许后台更新。保留搜索条件、客户和分页；未提交搜索、审核表单及业务保存期间暂停应用更新。
- 运营付款审核列表加入同步。商家新凭证可自动出现在客户列表；进入审核表单后保护正在核对的内容。
- 客服工单、回复及客户目录加入后台快照；订阅可用时由通知触发重读，并每10秒轮询兜底，无需新增数据库迁移。
- 客服详情仅更新对话历史，保留新咨询、客服配置和回复的原始输入节点及事件，避免打断输入。客服记录按批次完整读取。
- 读取失败区分网络、会话、权限和功能版本，提供三语言提示和重新加载。已有业务记录保留并标记可能未更新；初次加载失败不开放旧版业务表单。
- 客户目录请求失败不再吞错为空列表；账户切换、页面变化后的旧请求不会应用数据或弹出无关错误。
