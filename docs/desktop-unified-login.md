# 网页版统一登录（2026-11-04）

网页版登录页仅提供会员号或邮箱、密码及一个登录按钮，不再选择商家、仓库或运营入口。登录成功后读取数据库 profiles.role：merchant 进入商家首页，warehouse_operator 进入仓库工作台，admin 进入运营看板。角色不按输入的会员号前缀推断。

保留现有页面访问限制与数据库权限。缺失资料、无效角色或停用账号拒绝进入；商家注册入口保留，内部员工账号仍由平台维护。支持回车提交及中文、英文、印尼语切换。

此次仅更新最新开发版网页根目录，不修改数据库、测试账号、已发布 H5 文件及开发首版。

验证：npm test 224/224 通过；本地隔离浏览器使用模拟数据库角色验证商家、仓库、运营自动进入，以及回车提交和三种语言。该浏览器验证不创建或修改业务数据。
