## 功能及交互

- 仅面向商家：邮箱或会员号登录、注册邮箱验证。内部员工已登录时显示电脑端入口，避免在 H5 展示仓库及运营界面。
- 底部五个入口：首页、包裹、＋预报包裹、订单、我的。主要操作为预报、合包、费用与付款凭证、物流查询。
- 包裹和订单用手机卡片展示，保留搜索、状态筛选、明细、预报编辑及删除的原有权限限制；列表滚动分批加载。
- 我的服务包括地址管理、运输计算器、消息与客服、深圳仓地址和退出登录。
- 中文、英文、印尼语切换；适配小屏、触屏按钮、底部安全区、表单输入以及弹窗。
- 顶部及“我的”均可切换账号；直接调用 SDK 退出本浏览器会话，成功后重新载入登录页并丢弃账号相关草稿。退出失败可重试，保存资料期间暂缓切换；从浏览器历史缓存恢复时重新校验登录。
- 复用仓库核定头程和尾程后一次付款的业务；付款仍是转账后提交凭证、运营审核，未增加自动扣款。

## 数据边界

H5 与最新开发桌面版使用同一个 Supabase 项目 `sqnxjyckgbazsqsafgrc`。商家账号、包裹、地址和订单数据相同。在手机修改业务记录，会同步影响该账号在桌面上看到的数据。两个入口不等于两个隔离数据库。

手机入口沿用业务授权，未扩大 RLS 或 Storage 权限。客户端继续使用 publishable key，未包含服务端密钥。旧开发首版项目 `bdxqphmzwojamyuboqmz` 不在 H5 发布文件中。

最新开发项目的认证 Redirect URLs 已添加精确的 H5 地址 `/eaztrans-latest-development/h5/`，供注册验证邮件返回手机入口；保留原有桌面地址和 Site URL，未添加通配符或修改邮件模板。

## 开发和发布

已有隔离服务 `http://127.0.0.1:4175/` 运行时，执行 `npm run dev:h5`，在 `http://127.0.0.1:4176/h5/` 验收。4176 仅代理本机 4175 的临时测试数据库，无需重启或清空已有预览数据。

`buildMobile` 先用独立发布构建器生成新目录，再加入 H5 资源；保持 `signupVerification: 'link'`。审核构建环境后，只将生成目录写入发布仓库的 `h5/`，提交并发布。H5 变更只更新 h5/；共享数据库变更需单独验证桌面行为，禁止改动开发首版。
